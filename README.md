# Watchdog

Ochrana detí pred online predátormi. Demo pre ideathon a ITAPA.

| Stránka | Čo to je |
|---|---|
| `/` | Rozcestník |
| `/hra/` | Interaktívna hra: zahraj sa za 10-ročnú Viki, vyber odpovede a zisti, kedy privolať pomoc (🆘) |
| `/demo/` | Pôvodné demo: zapni Watchdog a uvidíš, ako odhalí nebezpečné správy |

Čisté HTML/CSS/JS, bez buildu. Na Vercel stačí importovať repo (Framework: Other).
